Mental snapshot

  • 401 vs 403 is a contract. 401 means "who are you?" (missing or bad credential, send WWW-Authenticate). 403 means "I know you, and the answer is no" (for example insufficient_scope).
  • Never let the token pick its own crypto. Pin the accepted algorithms on decode. Compare secrets in constant time, and compute HMACs over the raw bytes you received.
  • An NSO service is a YANG list plus two statements: uses ncs:service-data and ncs:servicepoint NAME. That name is the join key to the template and to the Python callback.
  • Templates are captured, not typed. | display xml-template turns real device config into a template. You then swap the literals for {XPath} or {$VAR}.
  • NSO fails quietly. An XPath that returns nothing is silently skipped. commit dry-run | debug template is how you see what happened.
  • APIC REST is GET/POST/DELETE over DNs. Authenticate with aaaLogin, keep the cookie in a requests.Session, and use query-target vs rsp-subtree to choose what you select and what comes back.
  • Theme of the week: each of these tools has one identifier that ties the pieces together (token scope, servicepoint name, DN). Most failures come from a mismatch on that identifier.

L3: exam-depth details to keep straight

5.5. RFC 6750 §3.1 maps invalid_token to 401 and insufficient_scope to 403. FastAPI's security classes (APIKeyHeader, HTTPBearer, …) now return 401 "Not authenticated" with a WWW-Authenticate header when the credential is missing. Before 0.122.0 they returned 403, and the FastAPI how-to shows the subclass override (make_not_authenticated_error) that restores the old behaviour. If a test harness expects 403 for a missing key, that version change is the first thing to check. RFC 8725 is the reason the verifier, not the token, chooses the algorithm. For Webex, X-Spark-Signature is an HMAC-SHA1 of the request body. Hash the bytes before any JSON parsing and compare with hmac.compare_digest.

2.9.b. The when statement makes its parent conditional. The NSO 6.5 YANG page says the node cannot be configured while the expression is false, and is deleted automatically if it later becomes false. must rejects the commit and shows its error-message. Per the ncsc man page, NSO 6.5 does not support some YANG 1.1 features (empty type in a leaf-list, anydata), and it accepts a leafref inside a union without validating it.

2.9.a. Template tag inheritance: merge and nocreate pass down to children until another tag appears. create and replace apply only to the node they sit on, and that node's children behave as merge. Put nocreate on the device node so a typo in a device name can't create a new device entry. An empty node-set result is ignored. That is a feature when you use it on purpose and a bug when the XPath has a typo.

3.1 ACI. The APIC REST guide lists POST, GET and DELETE as the operations, and says you cannot rename an existing object. query-target (self|children|subtree) plus target-subtree-class choose which objects you select. rsp-subtree (no|children|full) chooses how much of each selected object comes back. page-size controls paging. In this run's fetch, the following were present only in the tool's summary and not in text I could read verbatim: delete via status="deleted", page numbering from 0, and a new token on every aaaRefresh. They're marked ⚠ below.

Solution (⚠ untested: not run against the sandbox; NED element names unverified) 
import os, secrets, requests, urllib3
from fastapi import FastAPI, Header, HTTPException
urllib3.disable_warnings()
app = FastAPI()
APIC, U, P, KEY = (os.environ[k] for k in ("APIC_HOST","APIC_USER","APIC_PASS","API_KEY"))

def guard(key: str | None):
    if key is None or not secrets.compare_digest(key, KEY):
        raise HTTPException(401, "Not authenticated", headers={"WWW-Authenticate": "APIKey"})

@app.get("/tenants")
def tenants(x_api_key: str | None = Header(default=None, alias="X-API-Key")):
    guard(x_api_key)
    s = requests.Session(); s.verify = False
    try:
        r = s.post(f"https://{APIC}/api/aaaLogin.json", timeout=10,
                   json={"aaaUser": {"attributes": {"name": U, "pwd": P}}})
        r.raise_for_status()
        q = s.get(f"https://{APIC}/api/class/fvTenant.json", timeout=15)
        q.raise_for_status()
    except requests.RequestException:
        raise HTTPException(502, "APIC request failed")
    return [o["fvTenant"]["attributes"]["name"] for o in q.json()["imdata"]]
module loop {
  yang-version 1.1;
  namespace "urn:ccie-lab:loop"; prefix loop;
  import ietf-inet-types { prefix inet; }
  import tailf-ncs { prefix ncs; }
  list loop {
    key name;
    uses ncs:service-data;
    ncs:servicepoint loop-servicepoint;
    leaf name { type string; }
    leaf device { mandatory true;
      type leafref { path "/ncs:devices/ncs:device/ncs:name"; } }
    leaf id { type uint16;
      must ". != 0" { error-message "Loopback id 0 is not allowed"; } }
    leaf ip { type inet:ipv4-address; }
  }
}
<config-template xmlns="http://tail-f.com/ns/config/1.0" servicepoint="loop-servicepoint">
  <devices xmlns="http://tail-f.com/ns/ncs">
    <device tags="nocreate">
      <name>{/device}</name>
      <config>
        <interface xmlns="urn:ios">
          <Loopback>
            <name>{/id}</name>
            <ip><address><primary>
              <address>{/ip}</address>
              <mask>255.255.255.255</mask>
            </primary></address></ip>
          </Loopback>
        </interface>
      </config>
    </device>
  </devices>
</config-template>

⚠ The NED element path (interface/Loopback/ip/address/primary) comes from the 2.9.a page's unverified list. Capture it with display xml-template instead of trusting this.

Recall check: 12 questions

5.5 Securing a REST API

1. A request carries a well-formed, unexpired JWT whose scope lacks the needed value. Which status and error code? And for a missing token?

403 with error="insufficient_scope" (RFC 6750 §3.1). A missing or invalid token gets 401, with invalid_token when a token was sent, plus a WWW-Authenticate header.

2. Why pass algorithms=[...] to the decoder instead of reading alg from the token header?

The header is controlled by whoever sent the token. If the verifier trusts it, an attacker can try alg: none or an RS256→HS256 key-confusion attack. RFC 8725 says the verifier decides which algorithms it accepts.

3. A Webex webhook receiver rejects every event, though the secret is right. Most likely cause and fix?

The HMAC is computed over parsed and re-serialized JSON, so the bytes differ from what Webex signed. Hash the raw body, use SHA-1 for X-Spark-Signature, and compare with hmac.compare_digest.

2.9.b NSO service YANG

4. Which two statements turn a YANG list into an NSO service, and what do you see if the template's name doesn't match?

uses ncs:service-data and ncs:servicepoint NAME. A mismatch leaves the package at oper-status file-load-error with "Unknown servicepoint" in error-info.

5. A leaf with when and a leaf with must both evaluate false. What does the operator see?

when: the node can't be configured. If it already exists and the condition becomes false, it is deleted automatically, with no error. must: the commit is rejected and its error-message is shown.

6. Name two YANG 1.1 features NSO 6.5 doesn't support, and one it accepts but doesn't enforce.

Not supported: the empty type in a leaf-list, and anydata. Accepted but not validated: a leafref inside a union. Source: ncsc man page.

2.9.a NSO service templates

7. Give the one-liner that captures r1's DNS config straight into a package as a template, and the name Python uses to apply it.

show running-config devices device r1 config ip name-server | display xml-template | save packages/<pkg>/templates/<name>.xml. Apply it with Template(service).apply('<name>', vars), without the .xml extension.

8. A template contains {/devcie} by mistake. What happens at commit, and how do you find it?

The XPath returns an empty node-set, which NSO ignores, so the config is silently missing. commit dry-run | debug template shows each expression's result and context.

9. Which template tags are inherited by children and which are not? What goes on <device>?

merge and nocreate are inherited until a new tag appears. create and replace apply only to their own node, and that node's children use merge. Put nocreate on <device>.

3.1 Python against APIC

10. Name the three APIC session endpoints and the token-handling detail that breaks naive caching.

aaaLogin (POST with name and pwd), aaaRefresh, and aaaLogout. On the 11-19 page, a refresh returned a new token, so replace the stored one, and the default timeout was 600 s. ⚠ This run could not confirm either detail verbatim.

11. Which HTTP verbs does APIC accept, and why can't you rename a bridge domain?

GET, POST and DELETE; there is no PUT. The name is part of the DN, and the guide states you cannot rename an existing object. To change a name, create a new object and delete the old one. You can also delete with a POST that sets status="deleted" (⚠ summary-only this run).

12. Which query parameters choose what gets selected, and which choose what comes back?

Selection: query-target (self/children/subtree), target-subtree-class, query-target-filter. Response: rsp-subtree (no/children/full), rsp-subtree-class, rsp-subtree-include, rsp-prop-include.
