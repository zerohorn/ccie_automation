2.8.a-c Terraform: loops, variables, graph

L1. Terraform builds a dependency graph from references between resources, then walks it. count and for_each multiply a resource into instances. Variables feed values in.

L2. for_each accepts a map or a set of strings. A list is not converted for you; wrap it with toset(), which drops order and duplicates. Inside the block each.key is the map key or set member, and each.value is the map value (equal to the key for a set). The graph walk is depth-first, a node starts when its dependencies finish, and a semaphore caps concurrent nodes at 10 by default.

L3. Keys must be known before remote operations, so you cannot key off a value that only exists after apply. Sensitive values and impure functions such as uuid or timestamp are rejected as keys. The flag is -parallelism=N on plan, apply and destroy. Use count only for on/off (0 or 1); index-based addressing shifts when you remove an early item (⚠ not on the fetched count page).

3.3.a pyATS testbed files

L1. The testbed file is the inventory pyATS uses to connect. It is YAML: a testbed block, a devices map, and per-device connections.

L2. Credentials can sit at testbed, device or connection level. A lookup starts at the child and walks to the parent. If the named credential (for example enable) is not found anywhere, the lookup falls back to default. Connection keys include protocol, ip (may be a hostname), port, class. via and alias defaults live under connections.defaults, not on a connection.

L3. The schema marks os optional, yet every example sets it; plugin selection depends on it (⚠ unverified). Markups keep secrets out of the file: %ENV{name} reads the shell, %ASK{prompt} prompts, %ENC{text} decodes a stored secret, %CLI{arg} reads a command-line argument. Quote any value starting with %, always after a colon. extends: layers testbed files, last in the list is the base.

5.3 OAuth2: obtain a token

L1. OAuth2 lets an app act on a user's behalf with a short-lived token instead of the user's password. RFC 6749 defines four grants: authorization code, implicit, resource owner password credentials, client credentials.

L2. Authorization code: send the user to the authorize endpoint, receive a code on your redirect URI, POST it to the token endpoint, get an access token (and often a refresh token). If the authorization request carried redirect_uri, the token request must repeat it identically.

L3. PKCE (RFC 7636): verifier is 43-128 characters from unreserved characters; S256 challenge is base64url (no padding) of SHA-256 of the verifier. code_challenge goes in the authorization request, code_verifier in the token request. If code_challenge_method is omitted it means plain, so send S256. Meraki specifics: auth code and refresh grants, code valid 10 min, access token 60 min, refresh token revoked after 90 days idle, refresh rotates (store the new one), client authenticates with HTTP Basic, host as.meraki.com.

2.2 Python CLI over a REST API

L1. A CLI is argument parsing, an HTTP client, and output with sane exit codes.

L2. add_subparsers() has required=False by default, so no subcommand leaves args.func undefined. Pass required=True. set_defaults(func=handler) attaches the handler to each subparser. A parse error prints usage to stderr and exits 2. requests applies no timeout unless you pass one; timeout=(connect, read) sets both. verify=True is the default and raises SSLError on a self-signed cert; point verify at a CA file or set REQUESTS_CA_BUNDLE. No retries by default; mount an HTTPAdapter with Retry.

L3. RESTCONF on IOS XE 17.5: PATCH updates, PUT creates or replaces, POST creates; success examples are 200 (read), 201 (create), 204 (PUT/PATCH/DELETE with no body). Calling .json() on a 204 raises, so test status and body first. Media type is application/yang-data+json. Device needs restconf, ip http secure-server and a privilege-15 AAA user.

Solution (⚠ unverified — test in lab) 
#!/usr/bin/env python3
import argparse, base64, hashlib, json, os, secrets, sys
import requests

def load(path):
    with open(path) as f:
        return json.load(f)

def cmd_testbed(a):
    out = ["testbed:", "  name: lab", "  credentials:", "    default:",
           '      username: "%ENV{LAB_USER}"', '      password: "%ENV{LAB_PASS}"',
           "devices:"]
    for n, d in load(a.devices).items():
        out += [f"  {n}:", f"    os: {d['os']}", f"    type: {d['type']}",
                "    connections:", "      cli:", "        protocol: ssh",
                f"        ip: {d['ip']}"]
    print("\n".join(out))
    return 0

def cmd_probe(a):
    bad = 0
    verify = False if a.insecure else (a.cafile or True)
    auth = (os.environ["LAB_USER"], os.environ["LAB_PASS"])
    for n, d in load(a.devices).items():
        if not d.get("restconf"):
            continue
        url = f"https://{d['ip']}/restconf/data/Cisco-IOS-XE-native:native/hostname"
        try:
            r = requests.get(url, auth=auth, verify=verify, timeout=(3, 10),
                             headers={"Accept": "application/yang-data+json"})
            r.raise_for_status()
            print(n, r.status_code, r.json() if r.content else "")
        except requests.RequestException as e:
            print(n, "ERROR", e, file=sys.stderr)
            bad += 1
    return 3 if bad else 0

def cmd_pkce(a):
    v = secrets.token_urlsafe(32)
    c = base64.urlsafe_b64encode(hashlib.sha256(v.encode()).digest()).rstrip(b"=").decode()
    print(len(v), v, c)
    return 0

p = argparse.ArgumentParser(prog="inv")
p.add_argument("--devices", required=True)
sub = p.add_subparsers(required=True, dest="cmd")
sub.add_parser("testbed").set_defaults(func=cmd_testbed)
pr = sub.add_parser("probe")
pr.add_argument("--cafile"); pr.add_argument("--insecure", action="store_true")
pr.set_defaults(func=cmd_probe)
sub.add_parser("pkce").set_defaults(func=cmd_pkce)
a = p.parse_args()
sys.exit(a.func(a))

2.8 Terraform

1. You delete the first item of a list that drives count. What happens, and what is the safer pattern?Instances after it shift down an index, so Terraform plans changes for them ⚠. Use for_each over a map or set with stable keys.
2. for_each = var.names fails when names is list(string). Why, and two fixes?Only a map or a set of strings is accepted. Wrap with toset() (order and duplicates lost), or build a map with a for expression.
3. Default apply concurrency, the flag that changes it, and what does depends_on cost?10 nodes; -parallelism=N on plan, apply, destroy. depends_on makes plans more conservative, with more values known only after apply ⚠ (11-02 fetch).

3.3.a pyATS testbed

4. A connection and its device define no credentials; the testbed defines only default. A task needs enable. What is used and in what order is it searched?Search connection, device, testbed for enable; not found, so default is used.
5. Where do via and alias defaults live, and what alias does connect() with no arguments give?Under connections.defaults. Alias is default ⚠ (11-03 fetch). A second session: connect(alias='vty_1', via='vty') ⚠.
6. Name three markups for secrets or input, and the quoting rule.%ENV{}, %ASK{}, %ENC{} (also %CLI{}). Quote any value starting with %, always right after a colon.

5.3 OAuth2

7. A token POST returns invalid_grant. Three client-side checks?Code expired or already used (Meraki: 10 min); redirect_uri not identical to the authorization request; PKCE verifier does not hash to the stored challenge. (Error code name per RFC 6749 s5.2 ⚠, section unread today.)
8. PKCE: verifier rules, challenge derivation, and which request carries which?Verifier 43-128 chars from letters, digits, -._~. S256 challenge = base64url, no padding, of SHA-256 of the verifier. code_challenge (+ method S256) in the authorization request; code_verifier in the token request. Omitted method means plain.
9. Meraki lifetimes, and what must your script do after each refresh?Code 10 min, access 60 min, refresh revoked after 90 days idle. Refresh rotates: save the new refresh token at once, the old one is revoked. Token endpoint uses Basic auth.

2.2 Python CLI

10. Running the CLI with no arguments raises AttributeError on args.func. Why and fix?add_subparsers is optional by default (required=False). Pass required=True; argparse then prints usage and exits 2.
11. A request to a powered-off router hangs; another to a self-signed device fails. Defaults and fixes?No timeout by default; pass timeout=(connect, read). verify=True raises SSLError; pass a CA file path or set REQUESTS_CA_BUNDLE. verify=False is for testing only.
12. PATCH succeeds, then .json() raises. Why, and the check order? Which codes appear in the IOS XE 17.5 examples?204 has no body. Check status, then whether a body exists, then decode. Examples: 200 read, 201 create, 204 for PUT/PATCH/DELETE.
